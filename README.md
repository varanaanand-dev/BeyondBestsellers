# Beyond Bestsellers

**An explainable, preference-based fashion discovery prototype built with Python, pandas, and Streamlit.**

## Overview

Beyond Bestsellers explores a common challenge in online fashion shopping: finding products that match an individual's preferences rather than relying only on popular or prominently featured items.

The project demonstrates how structured product information and user-selected preferences can support a more personalized shopping experience.

## Live Demo

**[Try Beyond Bestsellers](https://varanananand-beyondbestsellers.streamlit.app)**

Explore the interactive prototype by adjusting your budget, shopping category, occasion, and style preferences to see how the rule-based recommendation system ranks products.


## The Problem

Fashion e-commerce platforms offer extensive product catalogs, but discovering relevant items can still require significant browsing and filtering.

Beyond Bestsellers investigates how a preference-driven discovery experience could make product exploration more intentional, transparent, and user-centered.

## The Solution

The prototype allows users to explore fashion products based on their preferences through a rule-based recommendation approach.

The current version focuses on explainability: recommendations are generated using defined product attributes and preference-matching logic rather than a trained machine-learning model.

## Technologies Used

## Getting Started

Clone the repository:

```bash
git clone https://github.com/varanaanand-dev/BeyondBestsellers.git
cd BeyondBestsellers
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Launch the application:

```bash
streamlit run app.py
```

## Current Version

The current prototype includes a curated eight-product dataset, interactive preference controls, budget and category filtering, occasion-based matching, style preferences, and transparent rule-based recommendation scoring.

Each recommendation explains the factors that contributed to its score, making the system's decision process visible to the user.
